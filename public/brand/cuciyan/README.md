# Cuciyan Brand Assets Infrastructure

This directory structure is prepared for **Phase Rebrand 2** of the Cuciyan super app.

## Directory Overview

- `logo/`: Production vector and raster logos (horizontal, vertical, white, dark).
- `icon/`: App icons, favicon assets, and standalone brand mark icons.
- `app-icon/`: PWA and mobile app icon assets (192x192, 512x512, apple-touch-icon).

## Rules & Guidelines

- **DO NOT** delete or overwrite existing `FreshLaundry` assets in `public/` during Phase 1.
- Production logo assets will be placed here in **Phase Rebrand 2**.
